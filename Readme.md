## 📌 프로젝트명: 공공 전자인계·인수 업무 시스템 운영(SM)

**기간:** 2025.07 ~ 재직중  
**성과:** 공공 법정 업무 시스템의 안정적 운영을 유지하며, 지도·대외 연계 기능 개선을 통해 사용자 조회 및 업무 처리 편의성 향상

### 🔧 주요 업무

- 수탁 폐수 처리 전자인계·인수 업무를 처리하는 공공 시스템의 운영 및 유지보수(SM) 담당
- JSP 기반 업무 화면 유지보수 및 사용자 요청에 따른 기능 개선
- MyBatis 기반 DB 연계 로직 수정 및 신규 쿼리 작성
- 정기 데이터 처리를 위한 Batch 프로그램 운영 및 오류 대응
- Naver Map API / VWorld API 기반 위치·지도 시각화 기능 유지보수
- 대외 시스템(API) 연계 기능 운영 및 연계 오류 발생 시 로그 분석·조치

### 🧑‍💻 역할

1. 공공 업무 시스템 운영 중 발생하는 기능 개선 및 장애 대응 전담
2. 배치 처리 오류 및 대외 연계 실패 이슈에 대한 원인 분석 및 재처리 대응
3. 지도 API 연계를 통한 사업장·처리시설 위치 조회 기능 개선
4. 운영 환경(UNIX / JEUS) 기준 로그 분석을 통한 문제 해결
5. 형상관리(SVN) 기반 수정 이력 관리 및 운영 반영 프로세스 준수

### 🛠️ 주요 사용 기술

- Java / JSP
- eGovFramework
- MyBatis
- Batch
- Oracle DB
- JEUS / UNIX
- SVN
- Naver Map API / VWorld API

### 📈 성과

- 공공 법정 업무 시스템의 안정적 운영 유지 및 장애 발생 시 신속 대응
- 지도 기반 조회 기능 개선으로 사용자 위치 인식 및 업무 처리 효율 향상
- 배치 및 대외 연계 오류 대응 프로세스 정비를 통한 운영 안정성 확보

### 🧩 문제 해결 사례

- **대외 연계(API) 장애 발생 시 데이터 미반영 문제 해결**  
  → 연계 로그 분석을 통해 실패 지점 식별 → 재처리 및 예외 처리 로직 보완으로 데이터 누락 방지

## 📌 프로젝트명: 열차운행정보 분석 웹 제작

**기간:** 2024.05 ~ 2025.03  
**성과:** SignalR 기반 실시간 고장 알림 시스템 구축 → 평균 1초 이내 사용자 화면 자동 반영

### 🔧 주요 업무

- 차량에 부착된 열차운행정보장치로부터 수집되는 실시간 운행, 고장, 적산 데이터 기반 분석 웹 플랫폼 개발
- 노선도 기반 열차 위치 시각화 및 고장 정보 실시간 알림 기능 구현
- 실시간 고장 알림 처리 흐름 설계 및 UI 자동 갱신 기능 구현
- 실시간 열차 관제 화면 구현(기관사 화면과 동일한 관제 정보 제공)
- 장애 이력 통계 / 검색 필터링 기능 개발
- 사용자 피드백 반영 인터페이스 개선

### 🧑‍💻 역할

1. 고장 발생 데이터 수신부터 UI 알림까지 전 과정 단독 구현
2. SignalR 도입 제안 및 직접 설계·구현
3. 고장 알림 자동화 및 위치 갱신 기능을 통한 관제 업무 생산성 향상
4. 차량 고장 발생 시 조치 내역을 철도공사 ERP에 연계 전송
5. 코레일 사용자 피드백을 반영한 반복 개선 및 협업 대응

### 🛠️ 주요 사용 기술

- C#
- .NET Core 3.1
- SignalR
- Leaflet.js
- MSSQL
- SQL Dependency
- Service Broker
- IIS

### 📈 성과

- 평균 알림 반영 시간 1초 이내 달성
- 노선도 기반 트래킹으로 관제 효율 30% 이상 향상
- 사용자 만족도 조사에서 시각화 UI·알림 기능 항목 90% 이상 긍정 평가
- 현장 정비 인력을 위한 모바일 UI 기획 및 차기 플랫폼 연계안 기획 완료

### 🧩 문제 해결 사례

- **Chrome 장기 미사용 시 SignalR 연결 끊김 문제 해결**  
  → 주기적 Ping 및 자동 재연결 로직 구현으로 안정성 확보

## 📌 프로젝트명: 사내전산 알림 시스템 구축

**기간:** 2024.02 ~ 2024.04  
**성과:** 사내 개선 건의 1위였던 업무 누락 문제를 해결하기 위해 최초의 실시간 자동 알림 시스템 구축

### 🔧 주요 업무

- PLC 기반 설비 상태 및 사내 복지(카페 주문/제조 완료 등) 알림 자동화
- 카카오톡 공식 딜러사 비즈톡 API 연동 메시지 송신/응답 처리
- 알림용 데이터 테이블 구성 및 저장 구조 설계
- 메시지 전송 결과 로그 관리 및 조회 페이지 제작
- 다양한 내부 이벤트에 반응하는 상시 처리 구조 구성

### 🧑‍💻 역할

1. 알림용 DB 테이블 구성 및 트리거 설계
2. 비즈톡 API 연동을 통한 메시지 송신 및 결과 처리
3. C# WinForms 기반 상시 대기형 프로그램 구현
4. 전송 로그 관리 및 웹 기반 알림 이력 시스템 개발
5. 토큰 오류, 중복 발송 방지 등 운영 환경 이슈 해결

### 🛠️ 주요 사용 기술

- C#
- .NET 6.0
- Windows Forms
- MSSQL
- SQL Dependency
- Service Broker
- Kakao BizTalk API

### 📈 성과

- 사내 최초 실시간 알림 자동화 시스템 도입
- 업무 누락 이슈 해소 및 전달 프로세스 자동화
- PLC 알림, 주문·제조 완료 알림 등 실시간 반영

### 🧩 문제 해결 사례

- 토큰 만료 시 자동 재발급 처리 구현
- 중복 발송 방지 로직 추가
- 실패 응답 로그 기록 및 재전송 정책 마련

### 🔧 주요 업무
